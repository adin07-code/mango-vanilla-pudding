# Mango Vanilla Pudding — Tutorial Resep Modern

> *"Sinar Matahari dalam Setiap Sendok: Merayakan Lembutnya Mango Vanilla Pudding"* — oleh **Imel & Deana (XI Busana)**

Website tutorial interaktif untuk membuat **Mango Vanilla Pudding** 2 lapis (layer mangga & layer vanila) dengan tampilan editorial modern, animasi saat scroll, dan tata letak responsif untuk desktop maupun mobile.

## Fitur Utama
- **Animasi Scroll Modern**: Scroll progress bar, hero parallax (desktop), *scroll-reveal choreography* (`IntersectionObserver`), dan timeline 7 langkah yang terisi mengikuti posisi scroll.
- **Anatomi 2 Layer Interaktif**: Ilustrasi gelas puding yang menyorot lapisan Topping, Layer Vanila, dan Layer Mangga saat dipilih.
- **Kalkulator Skala Porsi (`½×`, `1×`, `2×`)**: Menyesuaikan takaran bahan otomatis untuk 5–6, 11, atau 22 cup.
- **Checklist Bahan & Salin Daftar Belanja**: Tandai bahan yang sudah siap dan salin daftar belanja dengan sekali klik.
- **Timer Memasak Bawaan**: Timer cepat (10 menit setengah set & 30 menit pendinginan kulkas) dengan notifikasi suara lembut.
- **Tips Anti Gagal Interaktif**: Visualisasi perbedaan teknik menuang saat setengah set vs teknik tusuk garpu.
- **Kartu Resep Infografis & Cetak Resep**: Lightbox layar penuh serta mode cetak (*print-ready*).
- **Tampilan Mobile Ramah Satu Tangan**: Dilengkapi *Bottom Quick Navigation Bar* dan menu hamburger.
